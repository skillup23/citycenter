# Доработки citycenter.ru по аудиту + промо-ролик

Дата: 2026-10-07. Ветка: `audit-fixes`. Полный чек-лист с формулировками «сейчас / сделать / проверка»:
https://claude.ai/artifact/B2dkTX37uGi8isL4xxVx1A

## Цель

Исправить проблемы, найденные аудитом 5 октября 2026 (безопасность, 152-ФЗ, мобильный первый экран, SEO, скорость, навигация),
и поставить на первый экран промо-ролик ТРК. Успех — каждый пункт проходит свою «проверку» из чек-листа на локальной сборке
(`next build && next start`) на 1440 px и 375 px.

## Решения, принятые с заказчиком

- Название везде: **ТРК «Сити Центр»** (прописные — только где того требует дизайн, через CSS `uppercase`).
- Видео: на первом экране — тизер 15 с без звука, по кругу, вместо `SliderMain`; кнопка «Смотреть ролик» открывает модальное окно
  с полной версией 3:00 со звуком. Видео в блоке «О нас» (`city_FHD_6.mp4`) остаётся.
- Работаем только локально. На сервер ничего не выкладываем, пока заказчик не посмотрит результат.
- Next.js 13.1.6 не обновляем.

## Видео

Исходники: `citycenter-promo.mp4` (тизер) и `citycenter-promo-3min.mp4` из проекта Remotion.
Кодирование ffmpeg → `public/video/`:

| Файл | Параметры | Ориентир размера |
|---|---|---|
| `teaser-1080.webm`, `teaser-1080.mp4` | 1920×1080, без звука, VP9 / H.264 | ≤ 3 МБ каждый |
| `teaser-720.mp4` | 1280×720, без звука — для экранов < 768 px | ≤ 1,5 МБ |
| `teaser-poster.jpg` (+ `.webp`) | первый значимый кадр | ≤ 150 КБ |
| `promo-1080.mp4` | 1920×1080, H.264 + AAC 128k, `+faststart` | ≈ 20 МБ |
| `promo-poster.jpg` | обложка для модального окна | ≤ 150 КБ |

Компоненты:
- `components/HeroVideo.js` — `<video autoplay muted loop playsInline preload="metadata" poster>`, `<source media>` для мобильной версии;
  при `prefers-reduced-motion: reduce` видео не запускается, остаётся постер. Пропорция контейнера `aspect-video`.
  Поверх — кнопка «Смотреть ролик» (≥ 44×44 px, видимый фокус).
- `components/VideoModal.js` — оверлей с `<video controls autoplay>`; `src` подставляется только при открытии; закрытие по Esc,
  крестику и клику по фону; фокус возвращается на кнопку; прокрутка страницы блокируется, пока окно открыто.

## Остальные правки (по пунктам чек-листа)

- **#2 Метрика**: удалить загрузчик Метрики из `pages/_document.js` (и `<noscript>`-пиксель); единственный загрузчик —
  `CookieBanner` после «Принять».
- **#3 логотип на мобильном**, **#4 первый экран**: закрываются `HeroVideo` + исправление размеров логотипа в `Header.js`.
- **#5** `lang="ru"` в `_document.js`.
- **#6** sitemap: скрипт `scripts/generate-sitemap.mjs` обходит `pages/` и данные бутиков/новостей, пишет `public/sitemap.xml`,
  запускается в `prebuild`. В `robots.txt` — строка `Sitemap:`. Без новых зависимостей.
- **#7** H1: на главной видимый H1 не добавляется в дизайн — скрытый `sr-only` H1 остаётся единственным, «Юридическая информация» → H2;
  H1 на `/parking`, `/events`, `/event_city`.
- **#8** уникальные `description` для всех страниц, передаваемые в `Layout`.
- **#9** JSON-LD `ShoppingCenter` в `Layout` (на всех страницах): адрес, гео, телефон, часы, `sameAs`.
- **#10** `og:image` (1200×630, `public/og/default.jpg`), `twitter:card`, `og:url`/`canonical` для всех страниц, а не только главной.
- **#11** название — единый вариант в title/описаниях/разметке.
- **#12** `YandexMap` монтируется, только когда блок контактов в 300 px от экрана (IntersectionObserver).
- **#13** `sizes` у `next/image` (логотипы, шоурум, новости, афиша); убрать дублирующую загрузку шоурума (CSS-скрытие → `<picture>`-подобный выбор через `sizes`/media).
- **#14** `poweredByHeader: false`; заголовки кэша для `/_next/static`, `/video`, изображений.
- **#15** меню: «События» → `/event_city` с заголовком «События», «Кинотеатр» → `/events` с заголовком «Кинотеатр». URL не меняем.
- **#16** якорь `#butiki`; `#bitiki` продолжает работать (пустой `<span id="bitiki">`).
- **#17** юридический блок с главной убрать, ссылка остаётся в меню/подвале.
- **#18** анимации: найти reveal-эффекты, сделать начальное состояние видимым, уважать `prefers-reduced-motion`.
- **#19** тап-зоны ≥ 44 px на мобильном; плавающие кнопки `ButtonRight` — компактнее и не поверх контента на < 640 px.
- **#20** красный баннер: внутренние отступы, перенос строк.
- **#21** ссылка «Все новости и акции» → `/news`.
- **#22** `https://city.kinext.ru`.
- **#23 (новый)** частые перезапуски процесса на сервере: собрать логи `pm2`, найти причину; исправление — отдельным решением.

## Конфигурация сервера (не применяется, готовится файлом)

`deploy/nginx-citycenter.conf`: 301 с http и без-www на `https://www.citycenter.ru`, HSTS, `server_tokens off`, gzip для текста,
долгий кэш для `/_next/static/` и `/video/`.

`npm run build` без ошибок; `next start`; для каждого пункта — его «проверка» из чек-листа в встроенном браузере на 1440 и 375 px;
сравнение веса главной (было ~3 МБ / 144 запроса).
